# Fit Travel — Tourism Website

A responsive, multi-page tourism website built with pure HTML and CSS. No JavaScript frameworks or libraries used.

## Live Demo

[View Site](https://ngaregabryan-spec.github.io/Tourism-website/)

## Pages

- **Home** — Hero section, featured destinations, and site navigation
- **Sign Up** — User registration page
- **Book Now** — Booking inquiry page

## Built With

- HTML5
- CSS3 — including Flexbox, Grid, animations, and scroll-driven effects

## Features

- Responsive layout
- CSS-only animations using `animation-timeline: view()`
- Clean navigation across multiple pages
- Terracotta and yellow-green color scheme
